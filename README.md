# Session 2 Assignment - Control Flow & Error Handling

## Description

This Python program demonstrates the use of control flow statements, loops, and error handling.

The assignment consists of four parts:

### Task 1: Number Classification
- Prompts the user to enter a number.
- Determines whether the number is Positive, Negative, or Zero.
- Determines whether the number is Even or Odd.
- Uses `if`, `elif`, and `else` statements.

### Task 2: Number Analysis
- Prompts the user to enter up to 5 numbers.
- Calculates the sum of the entered numbers.
- Counts positive and negative numbers.
- Stops early if the user enters `0`.
- Skips invalid inputs using exception handling.
- Uses `for` loops, `break`, `continue`, and `try/except`.

### Task 3: Exam Score Classification
- Prompts the user to enter 6 exam scores.
- Validates that scores are between 0 and 100.
- Classifies each score as:
  - Excellent (90 and above)
  - Good (75–89)
  - Average (60–74)
  - Poor (below 60)
- Displays a summary count for each category.

### Bonus Challenge
- Prompts the user to enter numbers separated by commas.
- Classifies each number as Positive, Negative, or Zero.
- Handles invalid inputs using `try/except`.
- Displays a summary count of positive, negative, and zero values.
